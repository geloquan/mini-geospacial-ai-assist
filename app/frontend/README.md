# Frontend (Monorepo Subproject)

This directory contains the React + TypeScript + Vite frontend for `mini-geospacial-ai-assist`.

## Important

This folder is part of the monorepo and is **not** a separate git repository.

Use git commands from the repository root:

`/home/runner/work/mini-geospacial-ai-assist/mini-geospacial-ai-assist`

## Commands

From repo root (preferred):

```bash
npm run frontend:dev
npm run frontend:lint
npm run frontend:build
```

From this folder:

```bash
npm run dev
npm run lint
npm run build
```
